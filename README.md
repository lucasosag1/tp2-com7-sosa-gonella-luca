## Descripción del proyecto
Portfolio personal multipágina desarrollado con React, Vite y React Router DOM
como Trabajo Práctico N°2. Amplía el portfolio del TP1 incorporando navegación
entre páginas mediante rutas, con un menú lateral fijo y un área de contenido
que cambia según la ruta seleccionada.

## Tecnologías utilizadas
- React
- Vite
- React Router DOM
- JavaScript (JSX)
- CSS

## Instalación
1. Cloná el repositorio:
   \`\`\`
   git clone [tu-link-de-github-aca]
   \`\`\`
2. Entrá a la carpeta del proyecto:
   \`\`\`
   cd [nombre-de-la-carpeta]
   \`\`\`
3. Instalá las dependencias:
   \`\`\`
   npm install
   \`\`\`

## Ejecución local
\`\`\`
npm run dev
\`\`\`
Luego abrir en el navegador la URL que indica la terminal (por defecto `http://localhost:5173`).
